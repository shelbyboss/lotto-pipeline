Extract

Python ดึงผลจาก GLO API (หวยไทย) และหน้าเว็บผลหวยลาว พร้อม retry/backoff

Validate

ตรวจรูปแบบตัวเลข, กันข้อมูลซ้ำ, ใช้เลข 4 ตัวเป็นหลักเมื่อแหล่งข้อมูลพิมพ์ผิด, unit test ก่อนทุกรอบ

Load + Analyze

เขียน CSV แบบ atomic แล้วคำนวณ chi-square, binomial test, walk-forward backtest เป็น stats.json

Serve

GitHub Actions commit ข้อมูลใหม่ → GitHub Pages เสิร์ฟ dashboard นี้อัตโนมัติ
